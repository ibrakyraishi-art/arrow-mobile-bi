## Контекст

План предполагал, что лист «Разрезы» шаблона план/факт показывает выполнение по клиенту или каналу так же, как по проекту (G03, история 32: «клиент → план / факт / % / отклонение»).

## Решение

Код и ревью волны 2 показали: план общий на проект (ADR 0006), поэтому выполнение каждого клиента «к общему плану» даёт ряд коротких красных полос. Это ложный сигнал провала. Теперь на каждую колонку-разрез «Разрезы» показывают сводную «колонка → факт, доля в факте %» по полям-объёмам и столбчатый график факта, без `· выполнение %` и без светофора. Долю в факте по главному объёму показывает круговая диаграмма (T03): у сводной в движке нет режима «процент от итога».

## Почему

- **Оставить выполнение к общему плану.** Отвергнуто: красные полосы у каждого клиента читаются как «все провалили», хотя проект в целом может идти по плану. Это против R11 («красиво», то есть понятно) и G03.
- **Раскладывать общий план по разрезам пропорционально доле.** Отвергнуто: выполнение у всех стало бы одинаковым, равным общему, а план стал бы выдуманным.
- **Ввести план на разрез.** Отвергнуто: это вне рамок (G09, ADR 0006).
- **Добавить в сводную режим «процент от итога».** Отложено: это доработка движка ради одного места, а круговая диаграмма даёт ту же информацию.

## Последствия

- Ответа на вопрос «какой клиент или канал отстаёт от плана» в шаблоне нет. Есть только «кто сколько дал».
- Текст приёмки истории 32 (таблица «клиент → план / факт / % / отклонение») расходится с решением. При перетесте ориентироваться надо на spec §10.
- Баер всё ещё может руками собрать график выполнения по клиенту из полей «План» и получить те же вводящие в заблуждение полосы. Предостерегает от этого только подсказка поля (история 30).
- Доля в факте для каждого объёма, кроме главного, видна только в сводной в абсолютных числах: процент есть только в круговой диаграмме по главному объёму.
